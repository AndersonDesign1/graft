# UI change

Anything a person sees. `graft-design` is the authority.

1. Load `graft-design`, pick its mode (shape, build, review, polish), and
   follow it.
2. If the right layout is unclear, settle it by building two quick
   variants and comparing screenshots, not by asking.
3. Use tokens and the existing components of the surface you are on. A
   missing component is a proposal for that surface's component set (in the
   docs, `examples/docs-site/src/components/mdx`), not a one-off style.
4. Verify with `graft-verify`: 1440px and 390px, light and dark, keyboard
   focus, no sideways scroll. Attach the screenshots to the PR.
5. Run [opening-a-pr](opening-a-pr.md).

**Reply:** what changed for the reader, before and after screenshots, and any
DESIGN.md rule you had to propose.
