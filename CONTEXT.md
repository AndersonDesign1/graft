# Domain glossary

The words this codebase uses, and what each one means here. One name per thing:
if you find two names for one concept, that is a defect — it is how the
insecure-bind warning drifted from the thing it was meant to describe.

## Content

**Authored content** — MDX files under `contentDir`, laid out as
`<collection>/<slug>.mdx`. **Git is authoritative for it.** If git and the index
disagree, git wins and the compiler rebuilds.

**Collection** — a named, Zod-validated document type. `file-authoritative`
(MDX on disk, the default) or `db-authoritative` (rows in Postgres, reached only
through typed functions). Mixing them is `AUTHORITY_MISMATCH`.

**Slug** — a document's identity inside its collection. Kebab-case, always
(`SLUG_RE`). It names one document; it is never a path, so it cannot contain
`/`, `\` or `..`.

**Index** — the derived, queryable projection of authored content. Postgres
(`content_index`) or a static SQLite artifact at `.graft/index.db`. Derived,
never authoritative: deleting it costs a `graft compile`, nothing more.

**Compilation** — one projection run, recorded as a row with the git SHA it read
and what changed. What makes "git wins" checkable, and what `revert` rewinds to.

## Operational data

**Record** — a row in `data_records`, owned by Postgres, belonging to a
`db-authoritative` collection. Orders, submissions, comments: things a visitor
creates that were never in git.

**Typed function** — the only way in or out of operational data. Declares its
input, access rule, rate limit, and whether it is `destructive`. Served
identically at `POST /api/fn/<name>` and through MCP `run_function`.

## Identity

**Actor** — who is calling: `{ kind, id, scopes }`. `kind` is `human`, `agent`
or `anonymous`. An `id` is stable, never a display name. Anonymous actors have
no id, which is why they cannot file approvals.

**Scope** — a permission on a credential, from an OIDC `scope` claim or
`GRAFT_DEV_SCOPES`. `content:write`, `approvals:decide`, `studio:read`,
`studio:write`. Being authenticated grants none of them.

**Rate identity** — what a rate limit counts against. The actor when known,
otherwise the connection's peer address. Never a client-supplied header, unless
the deployment declares how many proxies it controls (`trustedProxyHops`).

## The human gate

**Approval** — a request to run a destructive operation, awaiting a human. Bound
to the exact function and canonical input it was requested for, so approving one
call can never authorize a different one. One-shot.

**Requester / decider** — the two identities the gate keeps apart. Both are
established by the server; neither is ever supplied by the caller. A requester
can never be the decider (`APPROVAL_SELF_DECISION`), and an approval with no
identified requester cannot be decided at all (`APPROVAL_UNATTRIBUTED`).

**Destructive** — a function flagged as such is human-gated under every approval
policy. That is not configurable.

## Branching

**Branch** — a named line of content with its own index. `overlay` (rows tagged
by branch, reading through a parent chain) or `neon` (a physical database fork).
Both behind one `BranchHandle`.

**Scope** _(branching sense)_ — a resolved branch's read chain and write target.
Distinct from an authorization scope; when both could be meant, say
"branch scope" or "permission scope".

## Primitives

**Registry item** — an owned primitive (`comments`, `commerce`,
`scoped-access`). `graft add` **copies** its files into the project, shadcn-style
— so a project owns and edits its copy. The duplication between
`packages/registry/registry/*/graft/` and `examples/landing-page/graft/` is that
model being demonstrated, not something to deduplicate. `check:registry-drift`
asserts the copies still match, because the real hazard is a fix reaching one
and not the other.

**Barrel** — the generated `graft/index.ts` that merges every owned primitive.
Regenerated by `graft add`; never hand-edited.

## Surfaces

**MCP** — the agent surface, over stdio (`graft mcp`) or Streamable HTTP.
Anonymous callers are refused unless a mount explicitly opts in.

**Studio** — the optional human surface: an editor, the approval queue, the
changes drawer. Unauthenticated on loopback by design; scope-gated anywhere else.

**Adapter** — the thin translation between a runtime and Graft's Web-standard
handlers (`Request → Response`). The Node adapter in `graft serve` is one; a
Next.js route is another. Handlers never know which.
