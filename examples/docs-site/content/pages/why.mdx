  Built for how people ship now. Agents and the humans who run them.

  Dashboards lock agents out. Graft is open source and self-hostable. Content
  stays code so you and your agent ship through CLI and MCP without a panel.
faqs:
  - question: Does this replace developers?
    answer: >-
      No. You own the repo, review diffs, and decide destructive gates. Agents
      do the repetitive authoring and ops that already happen through chat tools.
  - question: What do I still decide?
    answer: >-
      Merges, schema, access rules, and every destructive operation. An agent
      can file an approval. Only you run graft approve. Runtime credentials
      cannot self-approve.
