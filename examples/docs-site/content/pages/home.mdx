---
title: Graft
tagline: >-
  Most of us already ship with agents more than by hand. Graft keeps content as
  code so you and your agent can author, branch, and deploy without living in a
  dashboard.
description: >-
  Open-source, self-hostable CMS for agents and the people who run them. MDX in
  git, one Zod schema, a derived index that needs no database to start. CLI and
  MCP for day-to-day work.
faqs:
  - question: Do I need a dashboard?
    answer: >-
      No. Write MDX, run the CLI, or drive MCP, and nothing else has to be
      running. A Studio ships in the box for the people who want one: run graft
      studio to edit content, decide approvals, and browse branches. It is
      optional, and every operation it performs also exists on the CLI and on
      MCP.
  - question: Is Graft open source and self-hostable?
    answer: >-
      Yes. Run the packages on your Postgres and S3-compatible store. One Docker
      image, split compose, or handlers embedded in your app. No Graft cloud
      required.
  - question: Is content stored in git?
    answer: >-
      Yes. Git owns authored content. Postgres holds a derived index. If they
      disagree, recompile. Git wins.
  - question: Who is this for?
    answer: >-
      You and your agent. Agents do most of the edits through MCP and the CLI.
      You own the repo, review diffs, and decide destructive gates.
  - question: How do I add a feature vertical?
    answer: >-
      Run graft add commerce (or comments, seo, faq). Source lands under graft/
      as TypeScript you own. No plugin black box.
---
