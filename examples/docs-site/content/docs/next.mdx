<p className="kicker">Render Graft content in a Next.js App Router project, from install to cache refresh.</p>

This guide adds Graft to a Next.js App Router project. By the end, your pages
read typed content in Server Components, render its Markdown with your own
components, and refresh only the pages whose content changed.

**Before you start**, you need a Next.js 15 or newer project using the App
Router, and a `graft.config.ts` with compiled content. If you have not got
those yet, run through [Getting started](/docs/getting-started) first. It takes
about ten minutes.

What `@usegraft/sdk-next` gives you:

- **Typed reads in Server Components.** Every result is typed from your schema.
- **One read per document per request.** If a layout and a page read the same
  document, Graft reads it once, using `React.cache`.
- **Markdown rendering on the server.** `<MdxBody />` renders a document's body
  without sending an MDX parser to the browser.
- **Targeted cache refresh.** `revalidateContent` refreshes only the pages whose
  content changed.

## 1. Configure next.config.ts

Wrap your Next.js config with `withGraft`. Today it does one thing: it keeps
`@usegraft/registry` out of the server bundle, because that package reads files
from disk at runtime. You need it when you mount Graft's MCP route
([step 5](#5-mounting-functions-and-mcp-route-handlers)). Plain content reads
work without it, but adding it now means you will not have to remember later:

```ts
// next.config.ts
import { withGraft } from "@usegraft/sdk-next/config";
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  // your existing Next.js options
};

export default withGraft(nextConfig);
```

## 2. Initialize the Graft client

Create a server-only client instance.

### Static Engine (no database required)

```ts
// lib/graft.ts
import { openStaticIndex } from "@usegraft/db";
import { createGraft } from "@usegraft/sdk-next";
import { collections } from "@/graft.config";

export const graft = createGraft({
  index: await openStaticIndex(".graft/index.db"),
  collections,
});
```

### Postgres Engine

```ts
// lib/graft.ts
import { createDb } from "@usegraft/db";
import { createGraft } from "@usegraft/sdk-next";
import { collections } from "@/graft.config";

export const graft = createGraft({
  db: createDb(process.env.DATABASE_URL!).db,
  collections,
});
```

`createGraft` automatically wraps queries in `React.cache`. Repeated calls for
the same document within a single page render (e.g., in a layout and a page)
are deduped into a single index read.

## 3. Read content in Server Components

You can query documents directly inside `app/[slug]/page.tsx`:

```tsx
// app/[slug]/page.tsx
import { notFound } from "next/navigation";
import { MdxBody } from "@usegraft/sdk-next";
import { graft } from "@/lib/graft";

interface PageProps {
  params: Promise<{ slug: string }>;
}

// Optional: Pre-render all pages at build time
export async function generateStaticParams() {
  const pages = await graft.listContent("pages");
  return pages.map((page) => ({ slug: page.slug }));
}

export default async function Page({ params }: PageProps) {
  const { slug } = await params;
  const doc = await graft.getContent("pages", slug);

  if (!doc) {
    notFound();
  }

  return (
    <article className="max-w-2xl mx-auto py-12">
      <h1 className="text-4xl font-bold">{doc.data.title}</h1>
      {doc.data.tagline && (
        <p className="text-xl text-gray-600 mt-2">{doc.data.tagline}</p>
      )}
      <div className="prose mt-8">
        <MdxBody source={doc.body} />
      </div>
    </article>
  );
}
```

## 4. Custom MDX components

The `<MdxBody />` component accepts custom React components to render within
your markdown content:

```tsx
import { MdxBody } from "@usegraft/sdk-next";

const components = {
  Callout: ({ children, title }: { children: React.ReactNode; title?: string }) => (
    <aside className="border-l-4 border-blue-500 bg-blue-50 p-4 my-4">
      {title && <h4 className="font-semibold text-blue-900">{title}</h4>}
      <div className="text-blue-800">{children}</div>
    </aside>
  ),
};

export default function DocumentBody({ source }: { source: string }) {
  return <MdxBody source={source} components={components} />;
}
```

<Callout label="Safe by default" type="note">
  By default, `MdxBody` runs in `trust: "restricted"` mode. This allows standard
  Markdown, GFM, and safe JSX components with string attributes, while blocking
  unsafe runtime script execution (`{process.env.SECRET}`, `import`, `export`).
  See [MDX safety](/docs/mdx-safety).
</Callout>

## 5. Mounting functions and MCP route handlers

If you use Graft typed functions or wish to expose an authenticated MCP endpoint
to remote AI agents, mount them directly as Next.js Route Handlers:

### Typed Functions Route (`POST /api/fn/[name]`)

```ts
// app/api/fn/[name]/route.ts
import { createActorResolver } from "@usegraft/auth";
import { createFunctionsHandler } from "@usegraft/core";
import { createDb } from "@usegraft/db";
import { functions } from "@/graft.config";

const db = createDb(process.env.DATABASE_URL!).db;

// Resolve caller identity so mutations verify permissions & audit logs
const actor = createActorResolver({
  devTokens: process.env.GRAFT_DEV_TOKEN
    ? {
        [process.env.GRAFT_DEV_TOKEN]: {
          kind: "human",
          id: "owner",
          scopes: ["submissions:admin"],
        },
      }
    : undefined,
});

const handler = createFunctionsHandler({ db, functions, actor });

export const POST = handler;
```

### Agent MCP Route (`POST /api/mcp`)

```ts
// app/api/mcp/route.ts
import { createActorResolver } from "@usegraft/auth";
import { createDb } from "@usegraft/db";
import { createGraftMcpHandler } from "@usegraft/mcp";
import { collections, functions } from "@/graft.config";

const db = createDb(process.env.DATABASE_URL!).db;

const actor = createActorResolver({
  devTokens: process.env.GRAFT_DEV_TOKEN
    ? {
        [process.env.GRAFT_DEV_TOKEN]: {
          kind: "human",
          id: "owner",
          scopes: ["content:write"],
        },
      }
    : undefined,
});

export const POST = createGraftMcpHandler({
  contentDir: "./content",
  db,
  collections,
  functions,
  actor,
});
```

## 6. Cache revalidation

When content is recompiled (e.g. from a CI deployment or webhook), invalidate
Next.js cached pages using `revalidateContent`:

```ts
// app/api/revalidate/route.ts
import { revalidateContent } from "@usegraft/sdk-next";
import { type NextRequest, NextResponse } from "next/server";

export async function POST(request: NextRequest) {
  // Webhook security: fail closed if secret is unconfigured, then verify header or token
  const expected = process.env.GRAFT_WEBHOOK_SECRET;
  if (!expected) {
    return NextResponse.json({ error: "Webhook secret is not configured" }, { status: 500 });
  }

  const secret = request.headers.get("x-webhook-secret");
  const auth = request.headers.get("authorization");
  if (secret !== expected && auth !== `Bearer ${expected}`) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const body = (await request.json().catch(() => null)) as {
    branch?: unknown;
    changes?: { added?: unknown; changed?: unknown; removed?: unknown };
  } | null;

  if (
    !body ||
    !body.changes ||
    !Array.isArray(body.changes.added) ||
    !Array.isArray(body.changes.changed) ||
    !Array.isArray(body.changes.removed)
  ) {
    return NextResponse.json(
      { error: "Invalid payload: body must include { branch?: string, changes: ChangeSet }" },
      { status: 400 },
    );
  }

  const branch = typeof body.branch === "string" ? body.branch : "main";

  // Invalidates only the tags for documents that actually changed
  const tags = revalidateContent(branch, body.changes as any);

  return NextResponse.json({ revalidated: true, tags });
}
```
