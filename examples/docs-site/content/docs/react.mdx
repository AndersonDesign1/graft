<p className="kicker">Read Graft content from React code that runs in the browser.</p>

`@usegraft/sdk-react` gives you React hooks that read content over HTTP. Use it
when your React code runs in the browser and cannot open the index itself:

- a single-page app built with Vite, or
- an interactive component that loads content after the page is on screen,
  such as a live search box or a filter.

The hooks call Graft's [Content API](/docs/content-api), so something has to
serve it: `graft serve`, or the Content API handler mounted in your own
backend. The browser never receives a database connection or the index file.

<Callout label="Server-rendered app?" type="note">
  If you use Next.js, Astro, SvelteKit, TanStack Start, or React Router with
  loaders, read on the server with that framework's package instead. It reads
  the index directly, with no extra HTTP request.
</Callout>

<Callout label="Prefer to let your agent do it?" type="note">
  Paste this into your coding agent: "Add Graft content to this React app following https://graft.page/docs/react.md. Use createGraftHooks with the Content API endpoint at /api/content/v1."
</Callout>

## 1. Create your client and hooks

Initialize the client and generate typed hooks in `src/graft.ts`:

```ts
// src/graft.ts
import { createGraft, createGraftHooks } from "@usegraft/sdk-react";
import { collections } from "../graft.config";

// Point at your Graft Content API endpoint (e.g. running via `graft serve`)
export const graft = createGraft({
  endpoint: "https://cms.example.com/api/content/v1",
  collections,
});

export const {
  GraftProvider,
  useGraft,
  useContent,
  useContentList,
  useContentSearch,
} = createGraftHooks(graft);
```

Because your frontend imports your own `graft.config.ts`, all hooks are
fully typed without generating code or downloading remote schemas.

## 2. Wrap your application

Wrap your component tree in `<GraftProvider>`:

```tsx
// src/App.tsx
import { GraftProvider, graft } from "./graft";
import { BlogPost } from "./BlogPost";

export default function App() {
  return (
    <GraftProvider graft={graft}>
      <BlogPost slug="hello-world" />
    </GraftProvider>
  );
}
```

## 3. Read a single document

Use `useContent` to fetch a document by collection and slug:

```tsx
// src/BlogPost.tsx
import { useContent } from "./graft";

export function BlogPost({ slug }: { slug: string }) {
  const { data: post, loading, error, refresh } = useContent("posts", slug);

  if (loading) {
    return <div className="spinner">Loading post...</div>;
  }

  if (error) {
    return (
      <div className="error-box">
        <p>Failed to load: {error.message}</p>
        <button onClick={() => refresh()}>Retry</button>
      </div>
    );
  }

  if (!post) {
    return <p>Post not found.</p>;
  }

  return (
    <article>
      <h1>{post.data.title}</h1>
      {post.data.publishedAt && (
        <time>{new Date(post.data.publishedAt).toLocaleDateString()}</time>
      )}
      <div className="body-content">{post.body}</div>
    </article>
  );
}
```

## 4. Full-text search in the browser

Use `useContentSearch` to build responsive search inputs:

```tsx
// src/SearchBar.tsx
import { useState } from "react";
import { useContentSearch } from "./graft";

export function SearchBar() {
  const [query, setQuery] = useState("");
  const { data: hits, loading } = useContentSearch("docs", query, { limit: 10 });

  return (
    <div>
      <input
        type="search"
        placeholder="Search documentation..."
        value={query}
        onChange={(e) => setQuery(e.target.value)}
      />

      {loading && <p>Searching...</p>}

      <ul>
        {hits?.map((hit) => (
          <li key={hit.slug}>
            <a href={`/docs/${hit.slug}`}>
              <strong>{hit.data.title}</strong>
              <HighlightSnippet snippet={hit.snippet} />
            </a>
          </li>
        ))}
      </ul>
    </div>
  );
}

// Safely render search matches: escapes all markup while honoring <b> tags
function HighlightSnippet({ snippet }: { snippet: string }) {
  const parts = snippet.split(/(<\/?b>)/g);
  let isBold = false;

  return (
    <p>
      {parts.map((part, index) => {
        if (part === "<b>") {
          isBold = true;
          return null;
        }
        if (part === "</b>") {
          isBold = false;
          return null;
        }
        return isBold ? <mark key={index}>{part}</mark> : <span key={index}>{part}</span>;
      })}
    </p>
  );
}
```

## 5. Integrating with TanStack Query or SWR

Graft hooks provide simple state management (`data`, `error`, `loading`).
For advanced caching features like automatic deduplication, retry exponential backoff,
or stale-while-revalidate, use `graft.getContent` with TanStack Query or SWR:

```tsx
import { useQuery } from "@tanstack/react-query";
import { graft } from "./graft";

export function usePostQuery(slug: string) {
  return useQuery({
    queryKey: ["posts", slug],
    queryFn: () => graft.getContent("posts", slug),
  });
}
```

## What the browser can and cannot reach

- **No database access:** `@usegraft/sdk-react` communicates strictly over
  HTTP. It does not accept a `db` connection or database credentials, ensuring your
  database connection strings never leak into client-side bundles.
- **One branch per endpoint:** A remote Content API endpoint is pinned to a specific branch on the
  server. To preview branch content, point your client at the preview deployment's
  URL.
