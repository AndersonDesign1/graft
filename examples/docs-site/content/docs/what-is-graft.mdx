Graft is the open-source, self-hostable CMS for agents and the people who run
them.

Content is MDX in git. A Zod schema validates it. Postgres holds a derived
index. You and your agent work through the CLI and MCP — no dashboard required.

## You'll need

1. Node.js 20 or newer
2. A Postgres database URL (`DATABASE_URL`)
3. Optional: an S3-compatible store for assets (see [Configuration](/docs/configuration))

## Load-bearing ideas

1. **Git owns authored content.** Postgres is derived. Recompile if they disagree.
2. **One Zod layer** types compile, reads, functions, and MCP.
3. **MCP + CLI** are first-class. Errors carry a `fix`.
4. **Preview branches** are copy-on-write.
5. **Owned primitives** land as source via `graft add`.
