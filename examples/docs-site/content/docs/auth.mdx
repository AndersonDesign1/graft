<p className="kicker">Tell Graft who is calling, using the login your app already has.</p>

When someone calls one of your [typed functions](/docs/functions-and-access),
or an agent connects over MCP, Graft needs to know who they are. It uses that
to decide what they may do, and to record who did what in the audit log.

Graft does not create accounts or log anyone in. Your app, or an identity
provider such as Auth0, Clerk, or WorkOS, already does that and issues a
token. `@usegraft/auth` checks that token on each request and turns it into
the caller's identity, which Graft calls the **actor** (`FunctionActor` in
code).

## Where a caller's identity comes from

| Source | Use |
| --- | --- |
| OIDC bearer JWT | Production. Verified with jose against trusted issuers (JWKS inline, URL, or discovery). Checks `iss`, `exp`, `aud`. Scopes from `scope` / `scopes` / `permissions` |
| `GRAFT_DEV_TOKEN` | Local bootstrap. Optional `GRAFT_DEV_SCOPES` |
| No token | Anonymous |
| Bad token | `TOKEN_INVALID` (401). The server never downgrades silently to anonymous |

## Configure it

```sh
GRAFT_DEV_TOKEN=dev-secret
GRAFT_DEV_SCOPES=submissions:read,submissions:admin
GRAFT_TRUSTED_ISSUERS=https://your-idp.example
```

`GRAFT_TRUSTED_ISSUERS` is a comma-separated list of issuer URLs. Discovery loads
JWKS for each. `graft serve` parses that env itself. An embedded
`createActorResolver` does not. The library creates JWT verification only when you pass
`issuers`. Omit them and a valid bearer is `TOKEN_INVALID` (401).

## Create a resolver in code

```ts
import { createActorResolver } from "@usegraft/auth";

export const actor = createActorResolver({
  issuers: (process.env.GRAFT_TRUSTED_ISSUERS ?? "")
    .split(/[,\s]+/)
    .filter(Boolean)
    .map((issuer) => ({ issuer })),
  devTokens: process.env.GRAFT_DEV_TOKEN
    ? {
        [process.env.GRAFT_DEV_TOKEN]: {
          kind: "human",
          id: "owner",
          scopes: ["content:write"],
        },
      }
    : undefined,
});
```

Hand `actor` to `createGraftMcpHandler` and `createFunctionsHandler`. Each
`{ issuer }` URL is trusted for OIDC discovery. A Better Auth instance your app
hosts uses `betterAuthIssuer({ url })` instead of a bare issuer URL.

## Access rules

```ts
import { requireScopes } from "@usegraft/auth";

access: requireScopes("submissions:read"),
```

Anonymous and unscoped callers are denied. Combine with `public: true` only on
mutations that must accept strangers (contact forms).

## Identity for agents

- **stdio (`graft mcp`):** server holds `GRAFT_DEV_TOKEN` as default authorization.
  The secret does not enter the agent context.
- **HTTP:** connection bearer forwards into `run_function`. Optional
  `authorization` argument overrides (acting-as).

See [The agent surface](/docs/agent-surface).
