Graft provides typed read adapters for six major frontend frameworks, built on
a shared, high-performance query engine.

Every framework adapter exposes three core methods:
- `getContent(collection, slug)` — Read and validate a single document.
- `listContent(collection, options)` — List documents in a collection.
- `searchContent(collection, query)` — Full-text search with ranked hits and match snippets.

Reads are automatically typed by your `graft.config.ts` without codegen, and
invalid or soft-deleted rows are excluded.

## Shared query API

All server adapters share an identical, intuitive query surface:

```ts
// Initialize client with either SQLite static index or Postgres db
const graft = createGraft({ index, collections });

// 1. Read a single document
const home = await graft.getContent("pages", "home"); // Document | null

// 2. List documents
const docs = await graft.listContent("docs"); // Document[]

// 3. Full-text search
const hits = await graft.searchContent("docs", "branching"); // SearchHit[]
```

<Callout label="Low-level SDK Core" type="note">
  Framework adapters wrap `@usegraft/sdk-core` with framework-native caching
  (`React.cache` in Next.js, loaders in SvelteKit/TanStack). If you are building
  custom tooling without a frontend framework, `@usegraft/sdk-core` provides the
  underlying `client.getDocument()`, `client.listDocuments()`, and
  `client.searchDocuments()` methods directly.
</Callout>

Pass `branch` to resolve overlay or Neon preview branches. See
[Branching & previews](/docs/branching-previews). Pass `index` instead of `db`
to read a static SQLite artifact or a remote `graft serve` — the surface does
not change.

## Remote runtime

`createContentApiReader` implements the same `index` seam against a
`graft serve` process. Every server SDK keeps its existing surface; only the
transport changes. The endpoint is one branch, so a caller cannot switch a
production read onto preview content.

```ts
import { createContentApiReader } from "@usegraft/content-api";
import { createGraft } from "@usegraft/sdk-astro";
import { collections } from "../../graft.config";

export const graft = createGraft({
  index: createContentApiReader({
    endpoint: "https://cms.example.com/api/content/v1",
    headers: { authorization: `Bearer ${process.env.GRAFT_CONTENT_TOKEN}` },
  }),
  collections,
});
```

`graft serve` mounts the matching handler at `/api/content/v1/documents` and
`/api/content/v1/search`. See [Content API](/docs/content-api).
