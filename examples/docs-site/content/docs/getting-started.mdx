This guide walks you through creating a Graft project, compiling your first
MDX document, and reading it back with full TypeScript safety.

## Prerequisites

- **Node.js 22.16 or newer** (uses native `node:sqlite` for full-text search).
- That's all. A standard content project requires **no external database** and
  **no cloud account**.

---

## Quick start

To give you an immediate, hands-on feel for how Graft works, we use **Next.js (App Router)** as a concrete walkthrough example below.

<Callout label="Framework Agnostic" type="note">
  **Next.js is only an example.** Graft is completely framework-agnostic. If you are not using Next.js, you can build with **Astro**, **SvelteKit**, **Remix / React Router**, **TanStack Start**, or a **plain Node.js / TypeScript script** with zero frontend framework. All options share the exact same embedded SQLite index, query syntax, and TypeScript safety.
</Callout>

Choose your starting path:

<Tabs labels="Next.js (Example), Plain TypeScript (No Framework), Astro">

<Tab>

### Next.js App Router (Example)

<Steps>

<Step title="Install the Next.js SDK and CLI">

```sh
npm i @usegraft/sdk-next @usegraft/db
npm i -D @usegraft/cli
```

</Step>

<Step title="Initialize Graft">

```sh
npx @usegraft/cli init
```

This scaffolds `graft.config.ts`, creates sample content in `content/pages/home.mdx`,
and sets up the static index.

</Step>

<Step title="Compile your content">

```sh
npx graft compile
```

This validates your markdown files against the schema and writes an embedded
SQLite index to `.graft/index.db`.

</Step>

<Step title="Read content in a Server Component">

Create or update `app/page.tsx`:

```tsx
import { openStaticIndex } from "@usegraft/db";
import { createGraft } from "@usegraft/sdk-next";
import { collections } from "@/graft.config";

export const graft = createGraft({
  index: await openStaticIndex(".graft/index.db"),
  collections,
});

export default async function Page() {
  const home = await graft.getContent("pages", "home");

  if (!home) return <div>Page not found</div>;

  return (
    <main style={{ padding: "2rem", fontFamily: "sans-serif" }}>
      <h1>{home.data.title}</h1>
      {home.data.tagline && <p>{home.data.tagline}</p>}
      <pre style={{ background: "#f4f4f4", padding: "1rem" }}>{home.body}</pre>
    </main>
  );
}
```

Start your dev server:

```sh
npm run dev
```

Open `http://localhost:3000` to see your compiled MDX rendered with full type
safety!

</Step>

</Steps>

### Plain TypeScript (No Framework)

<Steps>

<Step title="Scaffold a project folder">

```sh
mkdir my-graft-site && cd my-graft-site
npm init -y
npm i @usegraft/db @usegraft/sdk-core
npm i -D @usegraft/cli tsx typescript @types/node
npx @usegraft/cli init
```

</Step>

<Step title="Compile content">

```sh
npx graft compile
```

This compiles `content/pages/home.mdx` into `.graft/index.db`.

</Step>

<Step title="Read and verify output">

Create `read.ts`:

```ts
import { openStaticIndex } from "@usegraft/db";
import { createClient } from "@usegraft/sdk-core";
import { collections } from "./graft.config";

const index = await openStaticIndex(".graft/index.db");
const graft = createClient({ index, collections });

const home = await graft.getDocument("pages", "home");

console.log("\n Successfully read document from Graft!");
console.log("Title:", home?.data.title);
console.log("Body:", home?.body.trim());
```

Run the script:

```sh
npx tsx read.ts
```

You will see:

```text
 Successfully read document from Graft!
Title: Hello, Graft
Body: Content lives in git. Postgres is the index...
```

</Step>

### Supported frameworks & runtimes

Graft works seamlessly across all modern JavaScript and TypeScript environments:

| Framework / Runtime | Guide / Adapter | Description |
| :--- | :--- | :--- |
| **Next.js** | [Next.js Guide](/docs/next) (`@usegraft/sdk-next`) | App Router Server Components, static generation, API routes |
| **Plain Node / TS** | [SDK Core Reference](/docs/sdk-reference) (`@usegraft/sdk-core`) | Standalone scripts, CLI utilities, background workers |
| **React (Client)** | [React Client Guide](/docs/react) (`@usegraft/sdk-react`) | Client-side hooks (`useContent`, `useContentSearch`) & TanStack Query |

| **SvelteKit, Remix, Vue** | [Reading Content](/docs/reading-content) (`@usegraft/db`) | Query directly against SQLite or via the HTTP Content API |

## Authoring documents

Authored content lives in Markdown / MDX files under `content/<collection>/<slug>.mdx`.
Frontmatter must satisfy the schema declared in `graft.config.ts`.

For example, `content/pages/about.mdx`:

```mdx
---
title: About Us
tagline: We build with code and AI agents.
---

Welcome to our project! This body content is pure MDX, versioned with your repository.
```

To update the query index after editing or creating files:

```sh
npx graft compile    # single build
npx graft dev        # watches content/ and recompiles on file changes
```

## Moving to Postgres (Optional)

Every project starts on the static SQLite engine. If your application later needs
**operational data** (user comments, contact forms, e-commerce orders) or
**copy-on-write preview branches**, upgrade to Postgres in three steps:

<Steps>

<Step title="Add your database URL to .env">

```sh
DATABASE_URL=postgres://user:password@localhost:5432/my_site
```

</Step>

<Step title="Switch the storage engine in graft.config.ts">

```ts
// graft.config.ts
export const index = "postgres";
```

</Step>

<Step title="Run database migrations and recompile">

```sh
npx graft db migrate
npx graft compile
```

Now update your frontend handle to pass `db` instead of the static index:

```ts
import { createDb } from "@usegraft/db";
import { createGraft } from "@usegraft/sdk-next";
import { collections } from "@/graft.config";

export const graft = createGraft({
  db: createDb(process.env.DATABASE_URL!).db,
  collections,
});
```

</Step>

</Steps>

## Troubleshooting & Common Errors

| Error Code | What it means | How to fix |
| :--- | :--- | :--- |
| `CONFIG_NOT_FOUND` | No `graft.config.ts` found | Run `graft init` or navigate to your project root |
| `STATIC_INDEX_NOT_FOUND` | Read attempted before first compile | Run `npx graft compile` before running your app |
| `STATIC_INDEX_UNSUPPORTED` | Node runtime lacks `node:sqlite` | Upgrade to Node.js 22.16 or newer |
| `NEEDS_DATABASE` | Postgres-only feature declared in static mode | Follow [Moving to Postgres](#moving-to-postgres-optional) |
| `SCHEMA_VALIDATION_FAILED` | Frontmatter does not match schema | Check the error output for missing or invalid fields |

Every Graft error includes an actionable `fix` property in the terminal explaining
exactly what to do next.
