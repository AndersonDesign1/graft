# @usegraft/tokens

> The Graft design tokens as plain CSS custom properties.

Part of [Graft](https://github.com/AndersonDesign1/graft), a CMS built so an AI agent is the primary operator.

## Install

```bash
npm i @usegraft/tokens@beta
```

## Use

```css
@import "@usegraft/tokens/tokens.css";
```

Or from JavaScript:

```ts
import "@usegraft/tokens/tokens.css";
```

Custom properties, not a framework. Override any of them in your own stylesheet and nothing in Graft fights you for it. The Studio uses these, so restyling the Studio is a matter of redefining the tokens rather than forking a component.
