# @usegraft/sdk-sveltekit

> SvelteKit adapter for Graft. Not yet published.

Part of [Graft](https://github.com/AndersonDesign1/graft), a CMS built so an AI agent is the primary operator.

This package is private while the SvelteKit surface is still being shaped. Use [`@usegraft/sdk-core`](https://www.npmjs.com/package/@usegraft/sdk-core) directly in the meantime: it is framework-agnostic and gives you the same typed reads and cache-tag contract.
