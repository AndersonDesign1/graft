## scoped-access (primitive)

`graft/scoped-access.ts` names your token scopes and exposes access rules.

- `requireModerator` gates a function so only callers whose token carries the
  `content:moderate` scope may run it (anonymous/unscoped → 401 UNAUTHORIZED).
- Edit the `SCOPES` map to match what your token issuer emits, then reuse the
  rules on any function's `access:`.
- Requires `@graft/auth` in the project (mint/verify tokens there).
